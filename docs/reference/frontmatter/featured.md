# `featured`

| | |
| --- | --- |
| Type | boolean |
| Required | no |
| Default | `false` |

Promotes the post to the Featured section of the homepage. At most three featured posts are shown, newest first.

Featured posts are not repeated in the Pinned list. The homepage gives the lead featured post a different treatment from the supporting ones (`featured-post--supporting` in `global.css`).

See [featured and pinned](../../content/featured-and-pinned.md).
