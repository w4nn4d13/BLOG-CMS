# Post slugs

`getPostUrl()` in `src/utils/posts.ts` builds every article URL:

```ts
const slug = post.data.slug || post.id.replace(/\.mdx?$/, '');
return `/posts/${slug}/`;
```

So the slug is either the `slug` frontmatter value or the file name without its extension.

## When to set `slug`

Set it only when the URL should differ from the file name, for example to keep an old public URL after renaming a file.

## Rules

- Slugs are not passed through `slugify()`. Write them exactly as you want the URL, lowercase with hyphens.
- A slug must be unique across all posts. `scripts/validate-content.js` reports `Duplicate slug` and exits with an error.
- Changing a slug of a published post breaks inbound links. Add a redirect.

Taxonomy slugs (category, tag, series) are different: they are generated by `slugify()`. See [slugify](../utils/slugify.md).
